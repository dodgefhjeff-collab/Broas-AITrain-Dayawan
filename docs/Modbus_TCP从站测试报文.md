# Modbus 从站测试报文说明

> 适用版本：室内训练机客户端（Modbus RTU + Modbus TCP 从站）  
> 默认 TCP 端口：**5020**，默认站号/Unit ID：**1**  
> 支持功能码：**0x04（读输入寄存器）**

---

## 1. 连接参数

| 项目 | RTU 串口从站 | TCP 网口从站 |
|------|-------------|-------------|
| 物理接口 | RS-232/RS-485 串口 | 以太网 |
| 默认波特率 | 9600 | — |
| 数据位/校验/停止位 | 8 / None / 1 | — |
| 默认站号 | 1 | 1 |
| 默认端口 | — | 5020 |
| 从站角色 | 工控机为从站，外部设备为主站 | 工控机为 TCP Server，外部设备为 TCP Client |

**程序配置路径：** 调试 → 从站设置 → 串口从站 (RTU) / 网口从站 (TCP)

## 2. 寄存器地址表

每个逻辑量占 **4 字节（2 个 Modbus 寄存器）**，功能码 **04** 只读。

| 地址 (hex) | 地址 (dec) | 名称 | 含义 | 数据来源 |
|------------|------------|------|------|----------|
| 0x0000 | 0 | AI_TestTime | AI 测量时间 | 当前时间戳 |
| 0x0002 | 2 | AI_ZD | AI 总氮 | Global.RecentValZD |
| 0x0004 | 4 | AI_AD | AI 氨氮 | Global.RecentValAD |
| 0x0006 | 6 | AI_COD | AI COD | Global.RecentValCOD |
| 0x0008 | 8 | AI_ZL | AI 总磷 | Global.RecentValZL |
| 0x000A | 10 | AI_XS | AI 高锰酸盐指数 | Global.RecentValXS |
| 0x000C | 12 | AI_Zhuodu | AI 浊度 | Global.RecentValZhuodu |
| 0x000E~0x001E | 14~30 | AI_Blank3~11 | 保留 | 0 |
| 0x0020 | 32 | ZD_TestTime | 仪表总氮测量时间 | Global.RecentValTimeZD |
| 0x0022 | 34 | ZD | 仪表总氮 | Global.YBRecentValZD |
| 0x0024 | 36 | AD_TestTime | 仪表氨氮测量时间 | Global.RecentValTimeAD |
| 0x0026 | 38 | AD | 仪表氨氮 | Global.YBRecentValAD |
| 0x0028 | 40 | COD_TestTime | 仪表 COD 测量时间 | Global.RecentValTimeCOD |
| 0x002A | 42 | COD | 仪表 COD | Global.YBRecentValCOD |
| 0x002C | 44 | ZL_TestTime | 仪表总磷测量时间 | Global.RecentValTimeZL |
| 0x002E | 46 | ZL | 仪表总磷 | Global.YBRecentValZL |
| 0x0030~0x003E | 48~62 | 保留 | 保留 | 0 |

**一次性读取全部有效因子：** 起始地址 `0x0000`，寄存器数量 `0x0020`（32 个寄存器 = 64 字节数据）。

> 仪表区（0x0020 起）按设备配置 `Global.EQNames` 过滤：未配置对应分析仪时，该因子寄存器返回 0。

## 3. 数据编码规则

### 3.1 浮点数（CDBA 字节序）

1. 将 float 转为 **IEEE754 大端** 4 字节
2. 交换字节索引 **0↔2**、**1↔3**（即 CDBA 序）

**示例：AI 总氮 = 4.965**

| 步骤 | 十六进制 |
|------|----------|
| IEEE754 大端 | `40 9E F3 74` |
| CDBA 编码后 | `F3 74 40 9E` |

**示例：AI 氨氮 = 6.589**

| CDBA 编码 | `53 96 40 D3` |

**解析公式（主站侧）：**

```
B0 B1 B2 B3  →  重组为 CDBA: B2 B3 B0 B1  →  按大端 float 解析
```

### 3.2 时间戳（4 字节）

- 基准时间：**2025-01-01 00:00:00 UTC**
- 值为距基准的 **秒数**（uint32）
- 字节排列（非标准大端）：

```
字节0 = (timestamp >> 8) & 0xFF
字节1 = timestamp & 0xFF
字节2 = (timestamp >> 24) & 0xFF
字节3 = (timestamp >> 16) & 0xFF
```

**示例：2025-01-02 00:00:00 UTC（偏移 86400 秒 = 0x00015180）**

| 编码结果 | `51 80 00 01` |

**解析公式（主站侧）：**

```
timestamp = B1 | (B0 << 8) | (B3 << 16) | (B2 << 24)
datetime  = 2025-01-01 UTC + timestamp 秒
```

## 4. Modbus TCP 报文格式

### 4.1 MBAP 头（7 字节）

| 偏移 | 字段 | 长度 | 说明 |
|------|------|------|------|
| 0 | Transaction ID | 2 | 事务标识，响应原样返回 |
| 2 | Protocol ID | 2 | 固定 `0x0000` |
| 4 | Length | 2 | 后续字节数（Unit ID + PDU） |
| 6 | Unit ID | 1 | 站号，默认 1 |

### 4.2 PDU 格式

**读输入寄存器请求（FC04）：**

```
Unit ID | FC(04) | StartAddr_Hi | StartAddr_Lo | Count_Hi | Count_Lo
```

**正常响应：**

```
Unit ID | FC(04) | ByteCount | Data[0..N-1]
```

**异常响应：**

```
Unit ID | FC(84) | ExceptionCode
```

| 异常码 | 含义 |
|--------|------|
| 0x01 | 非法功能码 |
| 0x02 | 非法数据地址（起始地址 > 0x003E） |
| 0x03 | 非法数据数量（Count = 0） |
| 0x04 | CRC 错误（仅 RTU） |

## 5. TCP 测试报文示例

### 5.1 读取全部因子（推荐）

**请求：** 站号 1，起始地址 0，读 32 个寄存器

```
00 01 00 00 00 06  01 04 00 00 00 20
|-- MBAP 头 --|    |----- PDU ------|
```

| 字段 | 值 | 说明 |
|------|-----|------|
| Transaction ID | `00 01` | 可自定义 |
| Protocol ID | `00 00` | 固定 |
| Length | `00 06` | 6 字节 PDU |
| Unit ID | `01` | 站号 1 |
| FC | `04` | 读输入寄存器 |
| Start Address | `00 00` | 地址 0 |
| Count | `00 20` | 32 个寄存器 |

**正常响应结构：**

```
00 01 00 00 00 43  01 04 40  [64 字节数据]
|-- MBAP 头 --|    |PDU: FC+长度+数据|
```

| 字段 | 值 | 说明 |
|------|-----|------|
| Length | `00 43` | 67 字节（1+1+1+64） |
| FC | `04` | 正常响应 |
| ByteCount | `40` | 64 字节数据 |

**响应数据区布局（64 字节）：**

| 字节偏移 | 寄存器地址 | 内容 | 示例值（测试数据） |
|----------|-----------|------|-------------------|
| 0~3 | 0x0000 | AI 测量时间 | `51 80 00 01`（2025-01-02 00:00:00） |
| 4~7 | 0x0002 | AI 总氮 | `F3 74 40 9E`（4.965） |
| 8~11 | 0x0004 | AI 氨氮 | `53 96 40 D3`（6.589） |
| 12~15 | 0x0006 | AI COD | `09 98 41 09`（8.595） |
| 16~19 | 0x0008 | AI 总磷 | `83 2A 3E 83`（0.256） |
| 20~23 | 0x000A | AI 高锰酸盐指数 | 实时值 CDBA |
| 24~27 | 0x000C | AI 浊度 | 实时值 CDBA |
| 28~31 | 0x000E | 保留 | `00 00 00 00` |
| ... | ... | 保留 | `00 00 00 00` |
| 32~35 | 0x0020 | 仪表总氮时间 | 实时时间戳 |
| 36~39 | 0x0022 | 仪表总氮 | 实时值 CDBA |
| 40~43 | 0x0024 | 仪表氨氮时间 | 实时时间戳 |
| 44~47 | 0x0026 | 仪表氨氮 | 实时值 CDBA |
| 48~51 | 0x0028 | 仪表 COD 时间 | 实时时间戳 |
| 52~55 | 0x002A | 仪表 COD | 实时值 CDBA |
| 56~59 | 0x002C | 仪表总磷时间 | 实时时间戳 |
| 60~63 | 0x002E | 仪表总磷 | 实时值 CDBA |

### 5.2 单独读取 AI 总氮

**请求：** 起始地址 0x0002，读 2 个寄存器（1 个 float）

```
00 02 00 00 00 06  01 04 00 02 00 02
```

**响应：**

```
00 02 00 00 00 07  01 04 04  [4 字节 AI 总氮值]
```

### 5.3 单独读取仪表 COD

**请求：** 起始地址 0x002A，读 2 个寄存器

```
00 03 00 00 00 06  01 04 00 2A 00 02
```

### 5.4 异常响应示例

**非法功能码（请求 FC=0x03）：**

请求：
```
00 04 00 00 00 06  01 03 00 00 00 20
```

响应：
```
00 04 00 00 00 03  01 83 01
```

**非法地址（起始地址 0x0040）：**

请求：
```
00 05 00 00 00 06  01 04 00 40 00 02
```

响应：
```
00 05 00 00 00 03  01 84 02
```

**寄存器数量为 0：**

请求：
```
00 06 00 00 00 06  01 04 00 00 00 00
```

响应：
```
00 06 00 00 00 03  01 84 03
```

**站号不匹配（配置站号 1，发送站号 2）：**

请求：
```
00 07 00 00 00 06  02 04 00 00 00 20
```

响应：**无响应**（从站忽略不匹配的 Unit ID）

## 6. Modbus RTU 测试报文示例

RTU 帧 = PDU + CRC16（低字节在前，高字节在后，多项式 0xA001）

### 6.1 读取全部因子

**请求：**

```
01 04 00 00 00 20  F1 D2
|---- PDU ----|  CRC|
```

**正常响应结构：**

```
01 04 40  [64 字节数据]  [CRC_Lo] [CRC_Hi]
```

### 6.2 读取 16 个寄存器（历史兼容示例）

**请求：**

```
01 04 00 00 00 10  F1 C6
```

### 6.3 单独读取 AI 总氮（RTU）

**请求：**

```
01 04 00 02 00 02  D0 0B
```

### 6.4 单独读取仪表 COD（RTU）

**请求：**

```
01 04 00 2A 00 02  50 03
```

### 6.5 RTU 异常响应

**非法功能码：**

```
01 84 01  83 24
```

**非法地址：**

```
01 84 02  19 25
```

**寄存器数量为 0：**

```
01 84 03  D2 D9
```

## 7. 工具测试命令

### modpoll（Modbus TCP）

```bash
# 读取全部 32 个输入寄存器
modpoll -m tcp -a 1 -r 0 -c 32 -t 4 <工控机IP> -p 5020

# 读取 AI 总氮（地址 2，2 个寄存器）
modpoll -m tcp -a 1 -r 2 -c 2 -t 4 <工控机IP> -p 5020

# 读取仪表 COD（地址 42，2 个寄存器）
modpoll -m tcp -a 1 -r 42 -c 2 -t 4 <工控机IP> -p 5020
```

### modpoll（Modbus RTU）

```bash
modpoll -m rtu -a 1 -r 0 -c 32 -t 4 COM1 -b 9600
```

> `-t 4` 表示输入寄存器（功能码 04）

## 9. 注意事项

1. **防火墙**：确保工控机放行 TCP 5020 端口。
2. **网络**：外部主站与工控机需同网段可达。
3. **端口 502**：若改用标准 502 端口，Windows 可能需要管理员权限。
4. **RTU/TCP 站号独立**：串口站号（`StationNo`）与 TCP 站号（`TcpSlaveUnitId`）分别配置。
5. **数据实时性**：每次收到读请求时从 `Global` 刷新寄存器，保证返回最新采集值。
6. **CDBA 字节序**：主站解析 float 时必须按本文 3.1 节规则处理，不可直接按大端 float 读取。

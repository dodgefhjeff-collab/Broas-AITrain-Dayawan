# Modbus TCP 从站一般配置读取说明

> 适用：室内训练机客户端（水质工控机作为从站）  
> 日期：2026-08-18  
> 详细报文示例见：`docs/Modbus_TCP从站测试报文.md`

工控机对外提供水质实时数据。外部设备作为 **主站（Client）** 来读，工控机作为 **从站（Server）** 应答。本文档仅覆盖 **Modbus TCP（网口）**。

---

## 1. 工控机侧（从站）配置

路径：**调试 → 从站设置**

### 1.1 网口从站（TCP，推荐）

| 项 | 一般配置 |
|---|---|
| 角色 | TCP Server |
| 监听地址 | `0.0.0.0`（本机所有网卡） |
| 端口 | `5020` |
| 站号 / Unit ID | `1` |
| 功能码 | 仅支持 `04` 读输入寄存器 |

操作：端口填 `5020`，站号选 `1`，点 **TCP启动**。状态显示「监听中 0.0.0.0:5020」即为成功。

防火墙需放行 TCP **5020**。

（本节仅保留 TCP 配置，RTU 相关内容不在本文件中说明。）

---

## 2. 外部设备侧（主站）一般读取配置

多台上位机/采集器同时读时，**每台都填同一套参数**，不要给每台分配不同站号。

### 2.1 Modbus TCP

| 项 | 填写 |
|---|---|
| 协议 | Modbus TCP |
| 角色 | Client / 主站 |
| 服务器 IP | 水质工控机 IP |
| 端口 | `5020` |
| 从站地址 / Slave ID / Unit ID | `1` |
| 功能码 | `04` Read Input Registers |
| 起始地址 | `0` |
| 数量 | `32` |
| 轮询周期 | 建议 `1000` ms |

本机自测时，服务器 IP 填 `127.0.0.1`。

### 2.2 数据类型（主站解析）

| 项 | 说明 |
|---|---|
| 每个测点 | 占 **2 个寄存器（4 字节）** |
| 浓度值 | IEEE754 float，字节序 **CDBA** |
| 时间戳 | 距 `2025-01-01 00:00:00 UTC` 的秒数，4 字节非标准排列 |

**CDBA 解析：** 收到 `B0 B1 B2 B3` 后，重组为 `B2 B3 B0 B1`，再按大端 float 解析。

不要用 03 功能码，不要按 ABCD / DCBA 直接当 float 读，数值会对不上。

## 3. 寄存器地址（功能码 04）

推荐一次读完：起始地址 `0`，数量 `32`（64 字节）。

| 地址 | 名称 | 含义 | 类型 |
|---|---|---|---|
| 0 | AI_TestTime | AI 测量时间 | 时间戳 |
| 2 | AI_ZD | AI 总氮 | float / CDBA |
| 4 | AI_AD | AI 氨氮 | float / CDBA |
| 6 | AI_COD | AI COD | float / CDBA |
| 8 | AI_ZL | AI 总磷 | float / CDBA |
| 10 | AI_XS | AI 高锰酸盐指数 | float / CDBA |
| 12 | AI_Zhuodu | AI 浊度 | float / CDBA |
| 14~30 | 保留 | 固定 0 | — |
| 32 | ZD_TestTime | 仪表总氮测量时间 | 时间戳 |
| 34 | ZD | 仪表总氮 | float / CDBA |
| 36 | AD_TestTime | 仪表氨氮测量时间 | 时间戳 |
| 38 | AD | 仪表氨氮 | float / CDBA |
| 40 | COD_TestTime | 仪表 COD 测量时间 | 时间戳 |
| 42 | COD | 仪表 COD | float / CDBA |
| 44 | ZL_TestTime | 仪表总磷测量时间 | 时间戳 |
| 46 | ZL | 仪表总磷 | float / CDBA |
| 48~62 | 保留 | 固定 0 | — |

单独读某个因子时，起始地址用上表地址，数量填 `2`。  
未接入对应分析仪时，仪表区该因子返回 0。

## 4. 多设备同时读取

工控机只开 **1 个** TCP 从站，可接受多路 Client 同时连接（现场常见 1～4 台）。

```
设备1 ──┐
设备2 ──┤
设备3 ──┼──→ 工控机 IP : 5020 ，站号 1
设备4 ──┘
```

| 正确 | 错误 |
|---|---|
| 4 台都填站号 `1` | 分别填站号 1、2、3、4 |
| 都连同一 IP、同一端口 | 给每台分配不同从站端口 |
| 各自维持一条 TCP 长连接 | 把工控机配成 Client 去连设备 |

站号与工控机不一致时，从站不回包，主站表现为超时。

## 5. 本机模拟读取（无需真设备）

工控机从站启动后，本机可用 modpoll 模拟 1 路或多路读取：

```bat
modpoll -m tcp -a 1 -r 0 -c 32 -t 4 127.0.0.1 -p 5020 -l 1000
```

模拟 4 路：开 4 个命令行窗口，各执行上述同一条命令。

Modbus Poll 图形工具：开 4 个程序实例，每实例独立连接 `127.0.0.1:5020`，Slave ID=`1`，功能码 `04`，地址 `0`，数量 `32`。

## 6. 常见问题

| 现象 | 处理 |
|---|---|
| 连不上 | 工控机未点 TCP启动；端口不是 5020；防火墙未放行 |
| 超时无响应 | 站号不是 1；功能码不是 04 |
| 能读但数值不对 | 未按 CDBA 解析 float |
| 仪表因子为 0 | 该分析仪未接入，或尚未出数 |
| 跨电脑连不上 | 不在同一网段，或未 ping 通工控机 |

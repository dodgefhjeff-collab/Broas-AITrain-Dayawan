# 室内训练机 Modbus 从站总配置说明

> 适用：大亚湾室内训练机（水质工控机作为从站）  
> 日期：2026-08-19  
> 目标：按本文配置网段、端口和读取参数后，外部主站能稳定读到实时数据。

工控机对外提供水质实时数据。外部设备作为 **主站（Client）** 来读，工控机作为 **从站（Server）** 应答。现场只使用 **Modbus TCP（网口）**。

---

## 1. 推荐总参数（先按这套填）

只要网段通、从站已启动，主站按下表填写即可出数。

| 项 | 推荐值 | 说明 |
|---|---|---|
| 协议 | Modbus TCP | 不要选 RTU over TCP |
| 工控机角色 | TCP Server / 从站 | 程序监听，等别人来连 |
| 外部设备角色 | TCP Client / 主站 | 主动连工控机 |
| 监听地址 | `0.0.0.0` | 程序固定监听本机全部网卡，界面不用填 IP |
| 端口 | `5020` | 不要填标准 502，除非现场明确要求 |
| 从站地址 / Unit ID / Slave ID | `1` | 多台主站都填 `1` |
| 功能码 | `04` 读输入寄存器 | 不要用 `03` |
| 起始地址 | `0` | 十进制 0 |
| 数量 | `32` | 一次读完全部有效因子 |
| 轮询周期 | `1000` ms | 过快无意义，过慢不影响连通 |
| 浮点字节序 | **CDBA** | 浓度值必须按此解析 |
| 每个测点 | 2 个寄存器（4 字节） | 单独读某个因子时数量填 `2` |

**本机自测服务器 IP：** `127.0.0.1`  
**跨电脑读取服务器 IP：** `192.168.10.131`（工控机网口，见第 2 节）。

---

## 2. 网段规划（必须同一网段）

现场统一使用 **`192.168.10.0/24`**。工控机固定为 **`192.168.10.131`**。  
程序监听 `0.0.0.0:5020`，不绑定某一个 IP。能否连上，取决于主站是否也改到这个网段，并且能 **ping 通 192.168.10.131**。

### 2.1 现场网段（已定）

| 项 | 现场值 |
|---|---|
| 网段 | `192.168.10.0 / 24` |
| 子网掩码 | `255.255.255.0` |
| 工控机 IP | **`192.168.10.131`**（主站填这个） |
| 默认网关 | 同网段网关；纯局域网互读可不填 |
| DNS | 可不填 |

| 设备 | IP | 说明 |
|---|---|---|
| 水质工控机 | `192.168.10.131` | 从站，主站“服务器 IP”填这个 |
| 主站设备 1 | `192.168.10.21` | 采集器 / 上位机 / PLC，可改未占用地址 |
| 主站设备 2 | `192.168.10.22` | 可选 |
| 主站设备 3 | `192.168.10.23` | 可选 |
| 主站设备 4 | `192.168.10.24` | 可选 |

主站 IP 只要满足：前三段是 `192.168.10`，最后一段 **不要用 131**（避免和工控机冲突），也不要用 `0`、`255`。

### 2.2 判定是否同网段

掩码 `255.255.255.0` 时，前三段必须是 `192.168.10`：

- 工控机 `192.168.10.131` 与主站 `192.168.10.21` → 同网段，可以读
- 工控机 `192.168.10.131` 与主站 `192.168.1.21` → 不同网段，读不到
- 工控机 `192.168.10.131` 与主站 `10.0.0.21` → 不同网段，读不到

### 2.3 工控机怎么设成 192.168.10.131（Windows）

把连接现场交换机的那块网卡改成静态 IP：

1. 打开 **控制面板 → 网络和共享中心 → 更改适配器设置**。  
   或右下角网卡图标 → **打开网络和 Internet 设置 → 更改适配器选项**。
2. 选中现场网卡（不要选 Wi-Fi，除非现场走无线）→ 右键 **属性**。
3. 双击 **Internet 协议版本 4 (TCP/IPv4)**。
4. 选 **使用下面的 IP 地址**，按下面填：

| 项 | 填写 |
|---|---|
| IP 地址 | `192.168.10.131` |
| 子网掩码 | `255.255.255.0` |
| 默认网关 | 有路由器则填，例如 `192.168.10.1`；只局域网互读可留空 |
| 首选 DNS | 可不填 |

5. 确定、关闭。管理员命令行核对：

```bat
ipconfig
```

对应网卡的 **IPv4 地址** 必须是 `192.168.10.131`。

也可用管理员命令行直接改（把 `以太网` 换成 `ipconfig` 里看到的网卡名）：

```bat
netsh interface ip set address name="以太网" static 192.168.10.131 255.255.255.0
```

### 2.4 主站设备怎么加入这个网段

外部采集器 / 上位机 / PLC 也必须改到 `192.168.10.x`，否则 ping 不通、读不到。

| 项 | 填写 |
|---|---|
| IP 地址 | `192.168.10.21`（示例，可改 2～254，避开 131） |
| 子网掩码 | `255.255.255.0` |
| 默认网关 | 与工控机一致，或留空 |
| 服务器 / 从站 IP | **`192.168.10.131`** |
| 端口 | `5020` |

改完后在主站电脑执行：

```bat
ping 192.168.10.131
```

必须有应答。不通就先查网线、交换机、IP/掩码，不要先调 Modbus。

## 3. 端口与防火墙

| 项 | 值 |
|---|---|
| 协议 | TCP |
| 端口 | **5020** |
| 方向 | 入站（外部主站连进来） |
| 监听 | `0.0.0.0:5020`（全部网卡） |

### 3.1 工控机放行 5020（管理员命令行）

```bat
netsh advfirewall firewall add rule name="Modbus TCP 5020" dir=in action=allow protocol=TCP localport=5020
```

查看是否已放行：

```bat
netsh advfirewall firewall show rule name="Modbus TCP 5020"
```

第三方杀毒/安全软件若拦截入站，同样放行 TCP 5020。

### 3.2 端口占用

从站启动失败、提示端口被占用时：

```bat
netstat -ano | findstr :5020
```

确认没有其它程序占用 5020。不要把端口改成 502，除非现场明确要求（Windows 上 502 常需管理员权限）。

## 4. 工控机从站启动（必须先做）

路径：**调试 → 从站设置 → 网口从站 (TCP)**

| 界面项 | 填写 |
|---|---|
| 端口 | `5020` |
| 站号 | `1` |
| 操作 | 点 **TCP启动** |

成功标志：状态显示 **「监听中 0.0.0.0:5020」**。

未启动时，主站一定连不上。启动成功后会记住配置，下次程序启动会自动监听（`IsAutoStartTcpSlave=true`）。

---

## 5. 外部主站填写模板

多台上位机同时读时，**每台填同一套参数**，不要给每台分配不同站号或不同端口。

```
主站1 ──┐
主站2 ──┤
主站3 ──┼──→ 192.168.10.131 : 5020 ，站号 1 ，功能码 04 ，地址 0 ，数量 32
主站4 ──┘
```

| 主站配置项 | 填写 | 常见别名 |
|---|---|---|
| 协议 | Modbus TCP | Ethernet / TCP |
| 服务器 IP / 从站 IP | **`192.168.10.131`** | Host / Remote IP |
| 端口 | `5020` | Port |
| 从站地址 | `1` | Slave ID / Unit ID / 站号 |
| 功能码 | `04` | Read Input Registers |
| 起始地址 | `0` | Start Address / 寄存器地址 |
| 数量 | `32` | Quantity / Length |
| 地址基数 | 0 基地址 | 有的软件显示为 30001，本系统按 **0** 填 |
| 数据类型 | Float，字节序 CDBA | 见第 7 节 |

**不要这样配：**

| 错误 | 后果 |
|---|---|
| 站号填 2、3、4 | 从站不回包，主站超时 |
| 端口填 502 | 连不上（工控机默认听 5020） |
| 功能码 03 | 返回异常码 01 |
| 工控机配成 Client 去连设备 | 方向反了，读不到 |
| 每台主站分配不同端口 | 工控机只开一个 5020 |
| 起始地址填 1 或 30001 | 读错位置或读不到预期因子 |

## 6. 寄存器地址（功能码 04）

推荐一次读完：起始地址 `0`，数量 `32`（64 字节）。

| 地址 | 名称 | 含义 | 类型 |
|---|---|---|---|
| 0 | AI_TestTime | AI 测量时间 | 时间戳 |
| 2 | AI_ZD | AI 总氮 | float / CDBA |
| 4 | AI_AD | AI 氨氮 | float / CDBA |
| 6 | AI_COD | AI COD | float / CDBA |
| 8 | AI_ZL | AI 总磷 | float / CDBA |
| 10 | AI_XS | AI 高锰酸盐指数 | float / CDBA |
| 12 | AI_Zhuodu | AI 浊度 | float / CDBA |
| 14~30 | 保留 | 固定 0 | — |
| 32 | ZD_TestTime | 仪表总氮测量时间 | 时间戳 |
| 34 | ZD | 仪表总氮 | float / CDBA |
| 36 | AD_TestTime | 仪表氨氮测量时间 | 时间戳 |
| 38 | AD | 仪表氨氮 | float / CDBA |
| 40 | COD_TestTime | 仪表 COD 测量时间 | 时间戳 |
| 42 | COD | 仪表 COD | float / CDBA |
| 44 | ZL_TestTime | 仪表总磷测量时间 | 时间戳 |
| 46 | ZL | 仪表总磷 | float / CDBA |
| 48~62 | 保留 | 固定 0 | — |

单独读某个因子：起始地址用上表地址，数量填 `2`。  
未接入对应分析仪时，仪表区该因子返回 0；AI 区只要程序在运行就会刷新。

## 7. 数据类型（读通了但数值不对时看这里）

### 7.1 浓度值（float，CDBA）

1. 取出 4 字节 `B0 B1 B2 B3`
2. 重组为 `B2 B3 B0 B1`
3. 按 IEEE754 大端 float 解析

示例：AI 总氮 = 4.965，线上字节为 `F3 74 40 9E`。

不要按 ABCD / DCBA / BADC 直接当 float 读。

### 7.2 时间戳

- 基准：`2025-01-01 00:00:00 UTC`
- 值为距基准的秒数（uint32）
- 字节：`B0 B1 B2 B3` 还原为  
  `timestamp = B1 | (B0 << 8) | (B3 << 16) | (B2 << 24)`

## 8. 连通性验收（按顺序做，保证能读到数据）

在工控机上执行 1～3，在主站电脑/采集器上执行 4～6。

| 序号 | 检查项 | 操作 | 通过标准 |
|---|---|---|---|
| 1 | 网口 IP | `ipconfig` | 工控机 IPv4 为 `192.168.10.131` |
| 2 | 从站已启动 | 调试 → 从站设置 | 显示「监听中 0.0.0.0:5020」 |
| 3 | 端口在听 | `netstat -ano` 查找 5020 | 有 `LISTENING` |
| 4 | 同网段 ping | 主站 `ping 192.168.10.131` | 有应答，不超时 |
| 5 | 防火墙 | 见第 3.1 节 | 5020 入站已放行 |
| 6 | 读寄存器 | 见下方命令 | 返回 32 个寄存器，非超时 |

本机先自测（不经过网线）：

```bat
modpoll -m tcp -a 1 -r 0 -c 32 -t 4 127.0.0.1 -p 5020
```

主站电脑测工控机：

```bat
modpoll -m tcp -a 1 -r 0 -c 32 -t 4 192.168.10.131 -p 5020
```

参数含义：`-a 1` 站号 1，`-r 0` 起始地址 0，`-c 32` 数量 32，`-t 4` 功能码 04，`-p 5020` 端口。

Modbus Poll 图形工具：连接 `192.168.10.131:5020`，Slave ID=`1`，功能码 `04`，地址 `0`，数量 `32`。

## 9. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| ping 不通 | IP/掩码不同网段，或网线/交换机未通 | 按第 2 节改到同一网段，先 ping 通再读 |
| ping 通但连不上 5020 | 从站未启动，或防火墙拦截 | 确认「监听中」；放行 TCP 5020 |
| 连接超时无响应 | 站号不是 1 | 主站 Unit ID 改成 `1` |
| 有响应但异常 | 用了功能码 03 | 改成 `04` |
| 能读但数值不对 | 字节序不是 CDBA | 按第 7.1 节解析 |
| 仪表因子为 0 | 该分析仪未接入或尚未出数 | 先看 AI 区地址 2～12 是否有值 |
| 启动失败端口占用 | 其它程序占用 5020 | `netstat` 查占用并关闭，或停掉旧从站再启动 |
| 多台主站只有一台能读 | 有的站号填错或连了错误 IP | 全部改成同一 IP、端口 5020、站号 1 |

## 10. 现场交接核对清单

对接前双方确认以下全部打勾：

- [ ] 工控机 IP 已设为 `192.168.10.131`，掩码 `255.255.255.0`
- [ ] 主站已改到 `192.168.10.x`，能 `ping 192.168.10.131`
- [ ] 工控机从站已启动，状态为「监听中 0.0.0.0:5020」
- [ ] 防火墙已放行 TCP 5020
- [ ] 主站：端口 `5020`，站号 `1`，功能码 `04`，地址 `0`，数量 `32`
- [ ] 主站 float 按 CDBA 解析
- [ ] `modpoll` 或等价工具已读到 32 个寄存器

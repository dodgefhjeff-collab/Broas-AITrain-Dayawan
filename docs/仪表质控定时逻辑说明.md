## 1. 结论概览

「仪表质控」定时逻辑在 WinForms 客户端实现。调度与 UI 在 `FormSLPLC` 分部类中，命中后经 `SendYBData` 静默下发。

- 入口定时器：`_instrumentQCTimer`，间隔 **60 秒**
- 调度规模：已配置因子 × 2 核查（零点 LD / 标样 BY）
- UI：仅 `Global.EQNames` 中存在的因子显示对应 GroupBox（与仪表控制页一致）
- 命中条件：`Enabled=true` + 星期/时/分匹配 + 同分钟去重 + 因子已配置
- 命中动作：拼 Hex → `CalcCRC16` → `SendYBData`

---

## 2. 整体流程

```
InitInstrumentQC
    ├─ EnsureInstrumentQCAppSettingsExist / LoadInstrumentQCSchedulesFromConfig
    ├─ StartInstrumentQCTimer (Interval = 60000)
    │      └─ TickInstrumentQCSchedules
    │             ├─ Enabled + 时分 + 星期匹配
    │             ├─ Global.EQNames 含该因子 ?
    │             └─ 去重后 ExecuteInstrumentQCCommand 静默下发
    └─ InitInstrumentQCUI（仅零点/标样；按 EQNames 建 GroupBox）
```

---

## 3. 时间匹配规则

| 配置值 | 含义 |
|--------|------|
| `00` | 每天 |
| `0` | 星期日 |
| `1`–`6` | 周一～周六 |

「开启」= 关；「已开启」= 开。改时间点「保存配置」；开关切换立即落盘。

---

## 4. 触发动作

| 核查 | 前缀 | 指令尾段 | QC Remark |
|------|------|----------|-----------|
| 零点 | LD | `00 03` | `"2"` |
| 标样 | BY | `00 02` | `"1"` |

站址：ZD=`01` / AD=`02` / COD=`03` / ZL=`04`。

---

## 5. 配置键

`[LD|BY]Zhikong[ZD|AD|ZL|COD]`：`星期;小时;分钟;状态;核查浓度`

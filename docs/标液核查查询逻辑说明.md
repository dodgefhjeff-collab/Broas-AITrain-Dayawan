## 1. 结论概览

标液核查查询只读本地 `QCRecord` 表，**不连仪表、不重新计算合格判定**。打开「质控记录」后，默认 Tab「标样核查数据」立刻按 `Remark = "1"` 拉第一页。

- 入口菜单：`FunctionInfo.FullName = 质控记录`，`URL = LayoutManageMoudle.QCData`
- 类型过滤：标液/标样固定 `Remark = "1"`；同页另一个 Tab「零点核查数据」用 `"2"`
- 可选条件：因子模糊匹配、起始时间、截止时间
- 排序：`QCTime` 降序（最新在前）
- 分页：默认每页 **50** 条
- 列表列：因子、核查时间、数值（备注列绑定了但不显示）

## 2. 打开路径

```
登录客户端
    └─ 左侧菜单「后台管理」
           └─ 「质控记录」（Code=QCData）
                  └─ BroasClientNew.Aside_MenuItemClick
                         └─ CreateInstance("WaterStation.Client.LayoutManageMoudle.QCData")
                                └─ 构造函数同时查两套数据
                                       ├─ GetAllQCRecordBY()  → 标样核查 Tab（Remark=1）
                                       └─ GetAllQCRecord()    → 零点核查 Tab（Remark=2）
```

菜单由 `DataAPI.EnsureQCRecordMenu` 幂等写入：名称「质控记录」，描述「质控记录查询」，挂在「后台管理」下，并对全部角色补权限。旧地址 `BatteryManageMoudle.QualityControl` 会被改写到当前窗体。

无对应 `RoleFunctionInfo` 时提示「您没有此功能权限请联系管理员」，不打开窗体。

## 3. 查询流程

```
点击「查询」/ 打开窗体 / 翻页
        ↓
组装 QueryQCRecordDto
        ├─ QCName   ← txtQCNameBY（空则不加）
        ├─ SatrtTime← uidateStartTimeBY（空则保持 1900-01-01，接口忽略）
        ├─ EndTime  ← dateEndTimeBY（空则保持 1900-01-01，接口忽略）
        ├─ Remark   ← 固定 "1"
        ├─ PageIndex← 点查询时强制 1；翻页用分页控件页码
        └─ PageSize ← 分页控件每页条数（默认 50）
        ↓
DataAPI.GetAllQCRecordAsync
        ├─ 动态 WHERE（SqlSugar Expressionable）
        ├─ ORDER BY QCTime DESC
        └─ ToPageListAsync
        ↓
dvBYdata.DataSource = Result
uiPagination2.TotalCount = Total
```

### 3.1 三次触发点

| 触发 | 方法 | 页码 |
|------|------|------|
| 打开窗体 | 构造函数 `_ = GetAllQCRecordBY()` | 第 1 页，条件全空 |
| 点「查询」 | `QueryBY_Click` → `GetAllQCRecordBY` | 强制回到第 1 页 |
| 翻页 | `uiPagination2_PageChanged` | 使用当前页码，沿用上次条件对象 |

翻页时用字段 `_queryQCRecordDtoBY`，不再重新读界面。因此：**先改筛选条件，必须再点「查询」**，只翻页不会带上新条件。

`Init == true` 时忽略翻页事件，避免构造阶段改 `TotalCount` 误触发查询。

## 4. 筛选规则

对应属性 `queryQCRecordDtoBY`（`QCData.cs`）。

| 界面控件 | DTO 字段 | 写入规则 | SQL 等价 |
|----------|----------|----------|----------|
| `txtQCNameBY` 因子 | `QCName` | 非空才赋值，`Trim()` | `QCName LIKE '%' \|\| 输入 \|\| '%'` |
| `uidateStartTimeBY` 起始时间 | `SatrtTime`（拼写如此） | 文本非空才赋值 | `QCTime >= 起始时间` |
| `dateEndTimeBY` 截止时间 | `EndTime` | 文本非空才赋值 | `QCTime <= 截止时间` |
| 无控件 | `Remark` | 固定 `"1"` | `Remark = '1'` |
| `uiPagination2` | `PageIndex` / `PageSize` | 查询时页码=1；翻页时用控件 | `LIMIT / OFFSET` |

接口层判断「要不要加时间条件」：字段默认 `1900-01-01`，等于该哨兵值则不加。构造函数把两个时间框 `Text` 置空，所以首次进入**不加时间过滤**，查出全部标液核查记录。

时间框格式：`yyyy-MM-dd HH:mm`。截止时间是闭区间，精确到分钟；该分钟之后的秒级记录会被排除。

因子是 **Contains 模糊匹配**，不是下拉精确匹配。例如输入「氮」会同时命中「总氮」「氨氮」。

## 5. 接口实现

`DataAPI.GetAllQCRecordAsync`：

```csharp
var exp = Expressionable.Create<QCRecord>();
exp.AndIF(where.SatrtTime != new DateTime(1900, 1, 1), a => a.QCTime >= where.SatrtTime);
exp.AndIF(where.EndTime   != new DateTime(1900, 1, 1), a => a.QCTime <= where.EndTime);
exp.AndIF(!string.IsNullOrWhiteSpace(where.QCName), a => a.QCName.Contains(where.QCName));
exp.AndIF(!string.IsNullOrWhiteSpace(where.Remark), a => a.Remark == where.Remark);

var result = await cc.Queryable<QCRecord>()
    .Where(exp.ToExpression())
    .OrderBy(a => a.QCTime, OrderByType.Desc)
    .Select(a => new ResultQCRecordDto { ID = a.ID.SelectAll() })
    .ToPageListAsync(where.PageIndex, where.PageSize, totalCount);
```

等价 SQL：

```sql
SELECT *
FROM QCRecord
WHERE Remark = '1'
  AND QCName LIKE '%总磷%'          -- 因子有输入时
  AND QCTime >= '2026-09-01 00:00' -- 起始时间有输入时
  AND QCTime <= '2026-09-08 23:59' -- 截止时间有输入时
ORDER BY QCTime DESC
LIMIT 50 OFFSET 0;                 -- (PageIndex-1)*PageSize
```

数据库：程序目录下 `BroasAITrain.db`（SQLite）。首次访问时 `CodeFirst.InitTables<QCRecord>()` 建表。`QCRecord` **没有**单独查询索引（`MeasureData` 才有）。

接口始终 `IsSucceed = true`。空结果也是成功，网格为空，不会走界面「暂无数据」分支。该分支只在抛异常时出现。

## 7. 查到的数据从哪来

查询本身不采集。记录由仪表串口上报后写入，查询只按 `Remark=1` 读出来。

```
仪表完成标液/标样测量
    → 104 字节 Modbus 03 包
    → 解析 data[35]~[40] 时间、data[41]~[44] 数值
    → 月日有效 且 时间与上次不同
    → InsertQCRecord(..., Remark="1")
    → QCRecord 表
```

| 从站地址 | 因子名 `QCName` | 去重配置键 |
|----------|-----------------|------------|
| `01` | 总氮 | `byRecentValTimeZD` |
| `02` | 氨氮 | `byRecentValTimeAD` |
| `03` | COD | `byRecentValTimeCOD` |
| `04` | 总磷 | `byRecentValTimeZL` |

写入字段：`ID`（雪花）、`QCName`、`QCTime`、`LiuliangVal`、`Remark="1"`。

因此查询结果里看不到「理论标液浓度、偏差、合格/不合格」——客户端从未写入这些列。

## 9. 实现注意点

1. **点查询后分页条页码未必回到 1**  
   DTO 里 `PageIndex` 已写成 1，但没有把 `uiPagination2` 的当前页同步回去。数据是第一页，页码显示可能仍停在上一页。

2. **首次查询的 PageSize 绑反了**  
   `queryQCRecordDtoBY.PageSize` 读的是 `uiPagination1.PageSize`（零点 Tab）。两边默认都是 50，所以正常看不出来；若只改某一侧每页条数，首次点查询会串用。翻页事件里改回了 `uiPagination2.PageSize`。

3. **空数据不当失败**  
   `GetAllQCRecordAsync` 永不把 `IsSucceed` 设为 false，界面「暂无数据」提示实际上走不到。

4. **截止时间闭区间到分钟**  
   选当天 `23:59` 会丢掉 `23:59:01` 及之后的秒。需要含整天时，截止应选到次日 00:00 或把秒补到 59。

5. **无导出、无合格判定、无平台上传**  
   本查询只展示本地 SQLite 记录。

## 11. 自测步骤

1. 登录后打开「质控记录」，默认应看到「标样核查数据」，按时间倒序列表。
2. 因子输入「总磷」点查询，应只剩总磷；输入「氮」应同时出现总氮和氨氮。
3. 不填时间应查出全部 `Remark=1` 记录；填起始/截止后，`QCTime` 应落在闭区间内。
4. 超过 50 条时翻到第 2 页，条件应保持；改因子后只翻页、不点查询，网格条件不应变。
5. 切到「零点核查数据」再切回，标液列表不应被零点条件污染（两套 DTO 独立）。
